# Security Policy

## Reporting a Vulnerability

**Do not report security vulnerabilities through public GitHub issues.**

Open a [GitHub Security Advisory](../../security/advisories/new) with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

Expect acknowledgement within 48 hours.

## Scope

- `contracts/escrow-core` — fund locking, auth, dispute resolution
- `backend/` — API key handling, AI prompt injection
- `sdk/` — keypair exposure, RPC injection
